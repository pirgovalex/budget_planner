Документация на проекта - AI Бюджетен Планировчик

За какво става въпрос?
Това е уеб сайт, в който си записвате какво харчите, а той ви прави графики и ви дава съвети. Използвах Solid.js за визията (защото е супер бърз) и Python (FastAPI) за сървъра отзад. Също така вързах и един AI модел, който се опитва да познава категориите на разходите ви и да Ви дава идеи как да пестите.

Как да го тествате?
има  два тестови профила с готови данни:

--Трябва ви huggingface api token за да използвате ai функционалността!

1. Тестов Профил (Пълен с данни)
Този акаунт е "разработен" - има въведени транзакции, заплати, сметки и цели за почивка. Идеален е, за да видите как изглеждат графиките и анализите наготово.

Потребител: test_user

2. Демо Профил (По-празен)
Този е по-чист, ако искате сами да си въведете 1-2 неща и да видите как работи системата от нулата.

Потребител: demo
Парола: demo123

Какво може да правите вътре?
Вход: Логвате се с един от горните профили.
Таблото: Веднага ще видите колко пари имате и  диаграма за какво ги харчите.
Транзакциите:
Кликнете "Добави транзакция".
Напишете примерно "20 лв за дюнери".
как AI само ще се сети, че това е категория "Food".
AI Съветите: Отидете на "AI Insights". Тъй като API-тата за истински AI са скъпи и с лимити, съм направил "Симулационен режим". Той генерира примерни съвети, които изглеждат точно като истински, за да добиете представа как би работило в реална среда.
Това е общо взето! Проектът е правен с желание да е модерен, бърз и полезен. Надявам се да ви хареса.

**Изисквания:** Python 3.10+ и Node.js 18+
(Не съм използвал docker)

**Стъпка 1: Backend (Сървър)**
1. Отворете терминал в главната директория на проекта.
2. Изпълнете следните команди:
```bash
# 1. Създаване и активиране на виртуална среда
python3 -m venv venv
source venv/bin/activate  # За Windows: venv\Scripts\activate

# 2. Инсталиране на зависимостите
pip install -r backend/requirements.txt

# 3. Създаване на база данни и тестови потребители
python backend/migrate_data.py

# 4. Стартиране на сървъра
uvicorn backend.main:app --reload --port 8000
```
**(или start-backend.sh)**


**Стъпка 2: Frontend (Интерфейс)**
1. Отворете **НОВ** терминал.
2. Влезте в папка frontend и стартирайте:
```bash
cd frontend

# 1. Инсталиране на пакетите
npm install --legacy-peer-deps

# 2. Стартиране на интерфейса
npm run dev
```

Отворете браузъра на адрес: `http://localhost:5173`
